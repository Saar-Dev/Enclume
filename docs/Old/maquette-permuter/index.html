Permuter — maquette de la fenêtre de déclaration du joueur

Une action = une extension de fenêtre dédiée. Sur la ligne d'une arme, deux boutons ouvrent chacun leur extension à droite : ↻ Recharger (la liste des munitions, elle existe déjà) et ⇄ Permuter (la liste des armes disponibles pour la permutation). Il n'y a plus de section « Prendre en main » dans la colonne de gauche.

  • La ligne où l'on clique ⇄ est l'objet qui sera rangé : c'est le titre de l'extension (« Permuter — Scorpion »). « Mains nues » = une main libre reçoit l'objet.
  • Le bouclier a le même bouton ⇄ que les armes ; comme il n'attaque pas, il n'a pas d'autre extension.
  • Le coût est écrit sur chaque candidat : Ceinture = Préparation, Initiative −3 ; Sac = Action simple (exclusive avec une attaque ou un rechargement).
  • Un seul choix par Tour : cliquer un autre candidat remplace le précédent ; recliquer le candidat choisi l'annule.
  • Un candidat qui sera refusé est signalé en rouge mais reste cliquable : le joueur assume, le serveur tranche, le chat le dit.
  • La colonne de gauche montre l'état après permutation : l'objet choisi apparaît en main, l'objet remplacé disparaît.

4. Une permutation qui sera refusée : avertissement rouge, mais cliquable

Le personnage tient une Gatling (deux mains). Il veut prendre une grenade de la Ceinture : la Gatling devrait y être rangée et elle est trop lourde. La ligne est rouge mais reste cliquable : si le joueur la choisit, le serveur refusera à la résolution, l'action est perdue et le chat le dit. Depuis le Sac (grande capacité), la même Gatling rentre.
